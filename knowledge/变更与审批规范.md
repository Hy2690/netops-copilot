# 网络变更与审批规范

## 一、变更分级
- 标准变更（P3 级操作，如恢复冗余链路接口）：值班工程师审批即可执行。
- 重大变更（影响生产路由、BGP 会话重置、核心设备操作）：须网络组组长审批，且在变更窗口（工作日 00:00-06:00）内执行。

## 二、硬性要求
1. 任何配置变更必须有对应工单或审批记录，禁止无记录操作。
2. 变更前必须生成回退方案（rollback plan）；BGP 类操作必须确认双端配置一致。
3. 变更后必须验证协议状态与业务连通性，并在工单记录验证结果。
4. 故障应急修复可先执行后补单，但审批记录（含审批人、理由）必须当日补齐。

## 三、AI Agent 辅助操作约定（2026-09 起试行）
1. AI Agent 只允许执行只读命令；任何配置命令必须经人工审批。
2. Agent 发起的变更请求必须附执行理由，审批人对变更后果负责。
3. Agent 的一切操作以审计日志为准，纳入月度操作审计。
